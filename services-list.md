# Services List

## 1. Supabase
- Type: BaaS
- Use: Database, authentication, storage
- Role: Stores screenshot metadata, analysis results, and user data

## 2. Google Gemini API
- Type: SaaS (AI API)
- Use: Summarization, classification, embeddings
- Role: Enhances OCR data with semantic understanding

## 3. Apple Vision Framework
- Type: PaaS (on-device AI framework)
- Use: OCR (text extraction)
- Role: Extracts text locally from screenshots

## 4. PhotoKit (Apple)
- Type: PaaS
- Use: Access to user photo library
- Role: Detects and imports screenshots automatically

## 5. SwiftUI
- Type: Framework (Frontend)
- Use: UI development for iOS/macOS
- Role: User interface and interaction layer

## 6. Node.js + Express Server
- Type: PaaS / self-managed backend
- Use: API server, processing pipeline
- Role: Handles uploads, AI calls, and communication

## 7. Vite
- Type: Build tool
- Use: Development server and bundling
- Role: Frontend build and dev environment

## 8. WebSockets (ws)
- Type: Protocol
- Use: Real-time updates
- Role: Live communication between server and client

## 9. Multer
- Type: Middleware
- Use: File uploads
- Role: Handles screenshot upload to backend

## 10. GitHub
- Type: SaaS
- Use: Version control
- Role: Code hosting and collaboration
