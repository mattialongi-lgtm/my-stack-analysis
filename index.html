5. Triple Lock-in Analysis

💰

Financial

Supabase is predictable flat tiers; Firebase is "Pay-as-you-Scale" with potential spikes.

⚙️

Procedural

GCP (Vertex/Cloud Run) requires deep DevOps and IAM knowledge.

📦

Data

SQL allows easy export; Firestore is proprietary NoSQL, making "out-migration" hard.

6. Risk & Scalability Summary

Supabase Weakest Link: Edge Logic

Postgres handles scaling well, but intensive custom business logic in the backend (Express) can become a bottleneck if not correctly containerized and horizontally scaled early.

GCP Weakest Link: Complexity Creep

Google Cloud's permission model (IAM) can lead to deployment failures and security leaks if the team is small. Firestore NoSQL can lead to "data spaghetti" without strict schema enforcement.
